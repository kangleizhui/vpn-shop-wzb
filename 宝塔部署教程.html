云商城商城 · 宝塔面板部署教程

适用：宝塔 8.x / 9.x，Debian / Ubuntu / CentOS
安装包：vpn-shop-v1.0.zip
最终效果：前台卖套餐 → 支付 → 自动在 Hiddify 建号 → 用户拿到聚合订阅 → 后台看用量大屏

〇、先看这张表

步骤做什么大约耗时
1装 Nginx + PHP 8.3 + MySQL5 分钟
2添加站点、设运行目录 /public、配伪静态3 分钟
3上传解压安装包2 分钟
4访问 /install.php 完成安装2 分钟
5加两条计划任务2 分钟
6后台加服务器、套餐、支付5 分钟

一、环境准备

宝塔 → 软件商店，安装：

  • Nginx（1.22 以上都行）
  • PHP 8.3（8.1 也可以，别低于 8.1）
  • MySQL 5.7 / 8.0（也可以用 SQLite，免装数据库）

PHP 扩展

软件商店 → PHP 8.3 → 设置 → 安装扩展，确认已装：

扩展用途
pdo_mysql连 MySQL
curl调 Hiddify 面板、支付接口
mbstring中文处理
openssl加密密钥、微信支付
pdo_sqlite只有用 SQLite 才需要

禁用函数

PHP 设置 → 禁用函数 里，本项目不需要 putenv、proc_open、exec、shell_exec，保持宝塔默认即可。

如果你之前为了别的程序放开过，也不影响。

二、添加站点

宝塔 → 网站 → 添加站点：

项填什么
域名你的域名，如 shop.example.com
根目录默认 /www/wwwroot/shop.example.com
FTP不创建
数据库先不创建（第 4 步再建，或选 SQLite）
PHP 版本8.3

添加完成后进入 设置。

2.1 网站目录

设置 → 网站目录：

  • 运行目录：选择 /public ← 这一步不做，首页会 404
  • 防跨站攻击（open_basedir）：保持开启即可

2.2 伪静态

设置 → 伪静态，粘贴：

location / {
    try_files $uri $uri/ /index.php?$query_string;
}

保存。

没配伪静态的典型现象：只有首页能开，/query、/admin/login、/s/xxx 全部 404。

三、上传安装包

宝塔 → 文件 → 进入 /www/wwwroot/shop.example.com →

  • 上传 vpn-shop-v1.0.zip
  • 右键 → 解压

解压后如果多出一层 vpn-shop/ 目录，进入它，全选里面的内容剪切到站点根目录，保证结构是：

/www/wwwroot/shop.example.com/
├── app/
├── bin/
├── public/          ← 运行目录
│   ├── index.php
│   ├── install.php
│   └── assets/
└── README.md
正确：/www/wwwroot/站点/public/index.php
错误：/www/wwwroot/站点/vpn-shop/public/index.php

3.1 权限

宝塔 → 文件 → 右键站点目录 → 权限：

  • 所有者：www
  • 权限：755
  • 勾选「应用到子目录」

或者用终端：

chown -R www:www /www/wwwroot/shop.example.com
find /www/wwwroot/shop.example.com -type d -exec chmod 755 {} \;
chmod -R 775 /www/wwwroot/shop.example.com/data 2>/dev/null
chmod 775 /www/wwwroot/shop.example.com/app
app/ 要可写（安装时写 config.php），data/ 要可写（SQLite 和日志）。

四、建数据库

方式 A：MySQL（推荐）

宝塔 → 数据库 → 添加数据库：

项填什么
数据库名vpnshop
用户名vpnshop
密码点随机生成，记下来
字符集utf8mb4
权限本地服务器

方式 B：SQLite

不用建库，安装时选 SQLite 即可。适合小流量、单机、想省事。数据库文件会生成在 data/shop.db。

五、安装

浏览器打开：

https://你的域名/install.php

按向导填写：

  • 数据库类型：MySQL 或 SQLite
  • 数据库地址：127.0.0.1，端口 3306
  • 数据库名 / 用户名 / 密码：第 4 步创建的
  • 站点名称：如「云商城」
  • 管理员账号 / 密码：密码至少 8 位，记好

点「开始安装」。成功后会：

  • 创建全部数据表
  • 写入 3 个默认套餐
  • 生成 install.lock

⚠️ 安装完成后立刻做两件事

  • 删除 public/install.php
  • 确认 install.lock 存在（没有就手动建一个空文件）

不删的话，任何人都能重新跑安装向导覆盖你的数据。

六、申请 SSL

宝塔 → 网站 → 设置 → SSL：

  • Let's Encrypt → 勾选域名 → 申请
  • 开启 强制 HTTPS
支付回调必须是 HTTPS，微信 H5 / JSAPI 更要求备案域名，别用 IP 收款。

七、计划任务（关键）

宝塔 → 计划任务 → 添加任务，两条都要加。

7.1 用量同步（每 5 分钟）

项值
任务类型Shell 脚本
任务名称订阅用量同步
执行周期N 分钟 → 5 分钟

脚本内容：

runuser -u www -- /www/server/php/83/bin/php /www/wwwroot/shop.example.com/bin/sync_usage.php >> /www/wwwlogs/vpn-shop-sync.log 2>&1

7.2 到期 / 流量提醒（每 30 分钟）

runuser -u www -- /www/server/php/83/bin/php /www/wwwroot/shop.example.com/bin/notify.php >> /www/wwwlogs/vpn-shop-notify.log 2>&1

为什么必须 runuser -u www

宝塔计划任务默认以 root 运行。如果直接用 root 跑 PHP：

  • SQLite 会生成 root 所有的 shop.db-wal / shop.db-shm
  • 之后网站（www 用户）写库就会报 readonly / database is locked
  • 而且日志文件如果是 root 建的，www 也写不进去

所以统一用 www 身份跑。

找不到 PHP 路径时执行：

ls /www/server/php/*/bin/php

一般 8.3 就是 /www/server/php/83/bin/php。

验证是否真的在跑

tail -n 5 /www/wwwlogs/vpn-shop-sync.log

正常输出类似：

[2026-11-25 06:00:01] pools=1 ok=1 err=0 disabled=0 0.21s

没有日志 ≠ 在跑。宝塔计划任务页面显示「成功」只代表 shell 返回 0。

八、后台初始化

访问：

https://你的域名/admin/login

用安装时设置的管理员账号登录。登录后就是数据大屏，左上角三条杠是菜单。

8.1 添加 Hiddify 服务器

菜单 → 服务器 → 添加：

字段说明
名称留空自动生成「地区-城市」
管理地址Hiddify 超管链接，形如 https://面板域名/后台路径/超管UUID
密码面板管理员密码
地区留空自动按 IP 识别，也可手填「香港」「美国-洛杉矶」
面板时区留空即可，系统自动探测（每台独立，加美国/欧洲节点不用改）

保存后系统会自动登录面板、读取订阅路径、检测地区。

8.2 套餐

菜单 → 套餐：

  • single（单地区）：用户选一台服务器，只发那台的订阅
  • all（全地区）：用户买一次，系统在所有已上架服务器各建一个号，合成一个聚合订阅链接，按 UA 自动返回 Clash / sing-box / base64

设置好价格、流量、有效期后上架。

8.3 支付

菜单 → 设置 → 支付设置，三大类，每种方式独立配置：

  • 易支付：接口地址、PID、密钥；回调 /notify
  • 支付宝官方：电脑网站 / 手机网站 / 当面付，各自填 AppID、应用私钥、支付宝公钥
  • 微信官方：Native 扫码 / H5 / JSAPI，各自填商户号、证书序列号、私钥、APIv3 密钥

回调地址：

易支付    https://你的域名/notify
支付宝    https://你的域名/notify/alipay
微信      https://你的域名/notify/wechat

配置完建议先用 1 分钱的套餐真实支付一次，确认订单变「已支付」且自动建号。

8.4 邮件通知

设置 → 邮件通知：

字段QQ 邮箱示例
SMTP 服务器smtp.qq.com
端口465（SSL）
加密SSL
邮箱账号xxx@qq.com
授权码QQ 邮箱设置里生成的授权码，不是登录密码

先点「发送测试邮件」，收到后再勾选启用。

九、上线检查清单

☐ 首页能打开，套餐显示正常
☐ /admin/login 能登录
☐ /install.php 已删除，install.lock 存在
☐ 隐私/条款页（如有）可访问
☐ 计划任务日志每 5 分钟有新行
☐ 下一单测试订单 → 支付 → 自动建号
☐ /s/<token> 页面能打开，二维码正常
☐ 后台概览「今日流量」不是 0（有真实用量后）
☐ 手机打开首页 / 查询页 / 订阅页无横向滚动

命令行快速验证：

curl -I https://你的域名/
curl -I https://你的域名/admin/login
curl -s https://你的域名/install.php -o /dev/null -w '%{http_code}\n'   # 应该是 404

十、常见问题

首页 404 / 只有首页能开

运行目录没设成 /public，或伪静态没配。

500 / 白屏

看 /www/wwwlogs/你的域名.error.log。最常见是 PHP 版本低于 8.1，或 app/、data/ 不可写。

安装页提示数据库连接失败

  • 数据库名/用户名/密码核对
  • MySQL 8 的用户认证方式改成 mysql_native_password
  • 确认 pdo_mysql 扩展已装

后台加服务器提示登录失败

管理地址必须是超管链接（带 /后台路径/UUID），不是面板首页；密码是面板管理员密码。

流量一直 0.00GB

先看计划任务日志；再手动跑一次：

sudo -u www /www/server/php/83/bin/php /www/wwwroot/你的域名/bin/sync_usage.php

最近使用时间偏差几小时

系统会按每台面板的时区自动换算；如果某台面板探测不到，可在服务器编辑页手填「面板时区（小时）」，例如 9、-5、3.5。

订阅链接打开是乱码

那是客户端格式（base64）。给用户发 /s/<token> 页面，里面有流量、到期、二维码。

提醒邮件发不出

先在后台点「发送测试邮件」：

  • 535 → 授权码不对
  • 连接超时 → 主机商封了 465，换 587 + STARTTLS

十一、升级与备份

备份（建议每天）

宝塔 → 计划任务 → 备份网站 + 备份数据库；或手动：

tar -czf /www/backup/shop_$(date +%F).tar.gz -C /www/wwwroot shop.example.com
# MySQL
mysqldump -u vpnshop -p vpnshop > /www/backup/shop_$(date +%F).sql
# SQLite
sqlite3 /www/wwwroot/shop.example.com/data/shop.db ".backup '/www/backup/shop.db'"

升级

  • 先备份
  • 覆盖 app/ 与 public/ 下的文件
  • 保留 app/config.php 和 install.lock
  • 访问一次前台，确认无报错

附：目录说明

路径作用
public/网站运行目录，唯一对公网开放
app/后端代码与配置，禁止直接访问
data/SQLite 数据库、日志、面板 cookie
bin/sync_usage.php用量同步（5 分钟）
bin/notify.php到期/流量提醒（30 分钟）
install.lock安装锁，删除后会被要求重装
